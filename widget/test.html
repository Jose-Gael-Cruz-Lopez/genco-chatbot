Generation Conscious — widget test page

Three ways to run

  1. Offline stub, no server (zero keys): open this file with ?stub=1 appended, e.g. file:///…/widget/test.html?stub=1. An inline fetch mock in this page answers POST /chat and GET /history with canned JSON, so the full conversation UI — greeting, quick replies, typing indicator, reply bubbles, and reload-rehydrate (history survives reload within the tab via sessionStorage) — is testable completely offline.
  2. Offline stub server: run python widget/stub_server.py (stdlib only, default port 8000) and open this file normally. Same canned endpoints, served over HTTP with permissive CORS.
  3. Real backend: start the FastAPI app at http://localhost:8000 (requires real keys in backend/.env), then serve this page over HTTP from an allowed CORS origin: cd widget && python -m http.server 5500 and open http://localhost:5500/test.html. That origin is in the dev ALLOWED_ORIGINS default; opening via file:// sends a null origin the real backend's CORS policy rejects.

Stub-only test hooks (both stub modes): send the message fail to get an HTTP 500 (the widget must show the friendly error bubble), or empty to get a 200 with an empty reply (the widget must fall back to the friendly error text instead of a blank bubble). To restart the stubbed conversation, clear the tab's storage or use a new tab (session id lives in localStorage, stub history in sessionStorage).
